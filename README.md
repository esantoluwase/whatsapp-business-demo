# WhatsApp-first small business demo

## Files
- `index.html`: website structure and styling.
- `data.js`: all business-specific copy, menu items, prices, hours, and contact details.

## Customise for a prospect
1. Open `data.js`.
2. Replace the business name, city, headline, phone, WhatsApp number, verified address, map query, and Instagram URL.
3. Confirm the menu and prices with the business.
4. Add genuine reviews only. Keep `reviews: []` if there are none.
5. For an overseas pitch, change `currency` and adjust prices to the prospect's actual prices.

## Publish with GitHub Pages
Upload `index.html`, `data.js`, and this README to the root of a GitHub repository. In Settings → Pages, select Deploy from a branch, choose `main` and `/(root)`, then save.
